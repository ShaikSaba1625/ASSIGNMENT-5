# B3 - JDBC Insert Strategies

`JdbcExperiment` and `PassLoader` provide a small prepared-statement batch
example. `DatabaseMetaDataPrinter` displays server and table information.
`MultiRowAndLoadData` keeps the example to parameterized JDBC batches; local
file-loading features are not enabled.

Database rows and timing values depend on a working local MySQL setup. This
document contains no measurements or claims of database execution.
