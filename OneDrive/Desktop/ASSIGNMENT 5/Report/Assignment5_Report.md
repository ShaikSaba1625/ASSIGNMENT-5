# Assignment 5 Report

This project contains design notes and independently written Java examples for
file storage, buffered I/O, DAO structure, serialization, transactions,
parameterized SQL, batch inserts, and CSV migration.

The source is divided into task folders to make each concept straightforward
to compile and run. Database examples require a local MySQL setup. Any
machine-specific results should be recorded only after a real run.
