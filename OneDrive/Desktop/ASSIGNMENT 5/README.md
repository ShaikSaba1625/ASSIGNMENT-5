## Project Management

The project uses Maven for dependency management and project configuration.

## How to Build

Open the terminal in the project folder and run:

```bash
mvn clean package
```

## How to Run

Run the required Java program from its corresponding task folder.

For Maven-based execution, use:

```bash
mvn clean package
```

Then run the required class according to the project configuration.

## Database

The project includes JDBC and MySQL-related tasks. Database configuration and connection details are provided in the corresponding task files/configuration.
